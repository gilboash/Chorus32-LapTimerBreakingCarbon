Install an update

A release has two files and they are uploaded separately: firmware.bin is the program, spiffs.bin is this web interface. Install both from the same release, firmware first. The timer restarts after each one.

0%

If an update fails

If a web interface upload is interrupted the pages are gone, but the timer still serves a built-in upload form. Reconnect to its WiFi and open its address to try again. Only a failed firmware upload needs a cable, and the timer keeps running the old firmware until a new one is written completely.

— Do not power off during an upload
